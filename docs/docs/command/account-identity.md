# miren account identity

Linked sign-in identities

## Usage

```bash
miren account identity [flags]
```

## Subcommands

- [`miren account identity list`](./account-identity-list.md) — List your linked sign-in identities
- [`miren account identity unlink`](./account-identity-unlink.md) — Unlink a sign-in identity (cannot remove the last one)
