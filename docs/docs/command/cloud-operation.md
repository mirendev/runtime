# miren cloud operation

Cloud cluster lifecycle history

## Usage

```bash
miren cloud operation [flags]
```

## Subcommands

- [`miren cloud operation list`](./cloud-operation-list.md) — List server restart and upgrade operation history
- [`miren cloud operation show`](./cloud-operation-show.md) — Show a server operation's progress and outcome
