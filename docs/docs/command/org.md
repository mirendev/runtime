# miren org

Cloud organization commands

## Usage

```bash
miren org [flags]
```

## Subcommands

- [`miren org add-member`](./org-add-member.md) — Add an existing Cloud user to an organization (admin only)
- [`miren org cluster-list`](./org-cluster-list.md) — List clusters and mirrored status in an organization
- [`miren org create`](./org-create.md) — Create an organization and become its admin
- [`miren org list`](./org-list.md) — List your Miren Cloud organizations
- [`miren org member-list`](./org-member-list.md) — List organization members
- [`miren org member-search`](./org-member-search.md) — Search existing organization members for group membership
- [`miren org remove-member`](./org-remove-member.md) — Remove an organization member (admin only)
- [`miren org set-member-role`](./org-set-member-role.md) — Set an organization member's role (admin only)
- [`miren org show`](./org-show.md) — Show an organization and its members
