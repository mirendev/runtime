# miren cloud cluster

Cloud cluster commands

## Usage

```bash
miren cloud cluster [flags]
```

## Subcommands

- [`miren cloud cluster approve`](./cloud-cluster-approve.md) — Approve a pending cluster registration in Miren Cloud
- [`miren cloud cluster apps`](./cloud-cluster-apps.md) — List mirrored apps in a cloud cluster
- [`miren cloud cluster cloud-init`](./cloud-cluster-cloud-init.md) — Generate cloud-init user-data to install and enroll a new cluster (admin only)
- [`miren cloud cluster delete`](./cloud-cluster-delete.md) — Delete a Cloud cluster record (admin only); leaves server registration files unchanged
- [`miren cloud cluster list`](./cloud-cluster-list.md) — List your clusters in Miren Cloud
- [`miren cloud cluster nodes`](./cloud-cluster-nodes.md) — Show mirrored node inventory and sync state
- [`miren cloud cluster online`](./cloud-cluster-online.md) — Check cluster connectivity under your Cloud access rules
- [`miren cloud cluster online-batch`](./cloud-cluster-online-batch.md) — Check connectivity for multiple accessible clusters
- [`miren cloud cluster operation`](./cloud-cluster-operation.md) — Show a server operation's progress and outcome
- [`miren cloud cluster operations`](./cloud-cluster-operations.md) — List server restart and upgrade operation history
- [`miren cloud cluster routes`](./cloud-cluster-routes.md) — Show mirrored cluster routes and sync state
- [`miren cloud cluster server`](./cloud-cluster-server.md) — Show server lifecycle status and supported actions
- [`miren cloud cluster show`](./cloud-cluster-show.md) — Show cloud cluster metadata and mirrored status
- [`miren cloud cluster update`](./cloud-cluster-update.md) — Update cloud cluster metadata (admin only)
- [`miren cloud cluster upgrade-policy`](./cloud-cluster-upgrade-policy.md) — Show the cluster's automatic-upgrade policy
