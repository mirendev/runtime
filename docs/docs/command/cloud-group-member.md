# miren cloud group member

Cloud group membership

## Usage

```bash
miren cloud group member [flags]
```

## Subcommands

- [`miren cloud group member add`](./cloud-group-member-add.md) — Add a user to an access group (admin only)
- [`miren cloud group member list`](./cloud-group-member-list.md) — List access group members
- [`miren cloud group member remove`](./cloud-group-member-remove.md) — Remove a user from an access group (admin only)
