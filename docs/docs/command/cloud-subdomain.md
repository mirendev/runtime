# miren cloud subdomain

Cloud subdomain claims and assignments

## Usage

```bash
miren cloud subdomain [flags]
```

## Subcommands

- [`miren cloud subdomain assign`](./cloud-subdomain-assign.md) — Assign a subdomain to a cluster (admin only)
- [`miren cloud subdomain claim`](./cloud-subdomain-claim.md) — Claim a subdomain for an organization (admin only)
- [`miren cloud subdomain domains`](./cloud-subdomain-domains.md) — List available subdomain base domains
- [`miren cloud subdomain list`](./cloud-subdomain-list.md) — List claimed organization subdomains
- [`miren cloud subdomain release`](./cloud-subdomain-release.md) — Release an organization's subdomain claim (admin only)
- [`miren cloud subdomain unassign`](./cloud-subdomain-unassign.md) — Remove a subdomain's cluster assignment (admin only)
