# miren server container

Run the miren server in a container (Docker or Podman)

## Usage

```bash
miren server container [flags]
```

## Subcommands

- [`miren server container install`](./server-container-install.md) — Install miren server in a container
- [`miren server container status`](./server-container-status.md) — Show status of miren server container
- [`miren server container uninstall`](./server-container-uninstall.md) — Uninstall miren server container
