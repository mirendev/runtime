# miren server lifecycle

Durable server restart and upgrade operations

## Usage

```bash
miren server lifecycle [flags]
```

## Subcommands

- [`miren server lifecycle list`](./server-lifecycle-list.md) — List recorded restart and upgrade operations
- [`miren server lifecycle run`](./server-lifecycle-run.md) — Execute or resume an operation in the foreground (normally launched by miren upgrade)
- [`miren server lifecycle show`](./server-lifecycle-show.md) — Show one restart or upgrade operation
