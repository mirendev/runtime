# miren cloud group

Cloud access groups

## Usage

```bash
miren cloud group [flags]
```

## Subcommands

- [`miren cloud group create`](./cloud-group-create.md) — Create an access group (admin only)
- [`miren cloud group delete`](./cloud-group-delete.md) — Delete a non-default access group (admin only)
- [`miren cloud group list`](./cloud-group-list.md) — List organization access groups
- [`miren cloud group member`](./cloud-group-member.md) — Cloud group membership
- [`miren cloud group show`](./cloud-group-show.md) — Show an access group
- [`miren cloud group update`](./cloud-group-update.md) — Update an access group, preserving omitted fields (admin only)
