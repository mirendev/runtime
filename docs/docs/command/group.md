# miren group

Cloud access groups

## Usage

```bash
miren group [flags]
```

## Subcommands

- [`miren group add-member`](./group-add-member.md) — Add a user to an access group (admin only)
- [`miren group create`](./group-create.md) — Create an access group (admin only)
- [`miren group delete`](./group-delete.md) — Delete a non-default access group (admin only)
- [`miren group list`](./group-list.md) — List organization access groups
- [`miren group member-list`](./group-member-list.md) — List access group members
- [`miren group remove-member`](./group-remove-member.md) — Remove a user from an access group (admin only)
- [`miren group show`](./group-show.md) — Show an access group
- [`miren group update`](./group-update.md) — Update an access group, preserving omitted fields (admin only)
