# miren subdomain

Cloud subdomain claims and assignments

## Usage

```bash
miren subdomain [flags]
```

## Subcommands

- [`miren subdomain assign`](./subdomain-assign.md) — Assign a subdomain to a cluster (admin only)
- [`miren subdomain base-domain-list`](./subdomain-base-domain-list.md) — List available subdomain base domains
- [`miren subdomain claim`](./subdomain-claim.md) — Claim a subdomain for an organization (admin only)
- [`miren subdomain delete`](./subdomain-delete.md) — Release an organization's subdomain claim (admin only)
- [`miren subdomain list`](./subdomain-list.md) — List claimed organization subdomains
- [`miren subdomain unassign`](./subdomain-unassign.md) — Remove a subdomain's cluster assignment (admin only)
