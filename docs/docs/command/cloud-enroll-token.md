# miren cloud enroll-token

Single-use cluster enrollment credentials

## Usage

```bash
miren cloud enroll-token [flags]
```

## Subcommands

- [`miren cloud enroll-token create`](./cloud-enroll-token-create.md) — Mint a cluster enrollment credential and bootstrap config (admin only)
- [`miren cloud enroll-token list`](./cloud-enroll-token-list.md) — List enrollment token status without secrets
- [`miren cloud enroll-token revoke`](./cloud-enroll-token-revoke.md) — Revoke an unused cluster enrollment token (admin only)
- [`miren cloud enroll-token show`](./cloud-enroll-token-show.md) — Show enrollment token state and bootstrap progress
