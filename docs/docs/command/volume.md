# miren volume

Cloud volume and backup inventory

## Usage

```bash
miren volume [flags]
```

## Subcommands

- [`miren volume list`](./volume-list.md) — List cloud volumes and active leases
- [`miren volume updates`](./volume-updates.md) — List a cloud volume's snapshots and update artifacts
