# miren session

Manage durable workload Sessions

## Usage

```bash
miren session [flags]
```

## Subcommands

- [`miren session create`](./session-create.md) — Create a Session from an app service
- [`miren session delete`](./session-delete.md) — Delete a Session
- [`miren session get`](./session-get.md) — Show a Session
- [`miren session list`](./session-list.md) — List Sessions
- [`miren session resume`](./session-resume.md) — Resume a Session
- [`miren session suspend`](./session-suspend.md) — Suspend a Session
