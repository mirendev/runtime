# miren deployment

Manage deployments

## Usage

```bash
miren deployment [flags]
```

## Subcommands

- [`miren deployment cancel`](./deployment-cancel.md) — Cancel an in-progress deployment
- [`miren deployment create`](./deployment-create.md) — Deploy an application
