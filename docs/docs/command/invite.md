# miren invite

Organization invite links and recipient actions

## Usage

```bash
miren invite [flags]
```

## Subcommands

- [`miren invite accept`](./invite-accept.md) — Join an organization using an invitation
- [`miren invite create`](./invite-create.md) — Create a shared organization invite link (admin only)
- [`miren invite list`](./invite-list.md) — List outstanding organization invite links (admin only)
- [`miren invite revoke`](./invite-revoke.md) — Revoke a shared organization invite link (admin only)
- [`miren invite show`](./invite-show.md) — Inspect an invitation as its recipient
- [`miren invite update`](./invite-update.md) — Update an invite's expiry, use cap or groups (admin only)
- [`miren invite url`](./invite-url.md) — Retrieve a copyable invite URL (admin only)
