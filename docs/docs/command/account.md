# miren account

Cloud profile and credentials

## Usage

```bash
miren account [flags]
```

## Subcommands

- [`miren account identity`](./account-identity.md) — Linked sign-in identities
- [`miren account key`](./account-key.md) — Cloud authentication keys
- [`miren account show`](./account-show.md) — Show your Cloud profile, organizations and enabled features
- [`miren account token`](./account-token.md) — Cloud token revocation
- [`miren account update`](./account-update.md) — Update your Cloud profile, preserving omitted fields
