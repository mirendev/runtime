# miren cloud invite

Organization invite links and recipient actions

## Usage

```bash
miren cloud invite [flags]
```

## Subcommands

- [`miren cloud invite accept`](./cloud-invite-accept.md) — Join an organization using an invitation
- [`miren cloud invite create`](./cloud-invite-create.md) — Create a shared organization invite link (admin only)
- [`miren cloud invite list`](./cloud-invite-list.md) — List outstanding organization invite links (admin only)
- [`miren cloud invite revoke`](./cloud-invite-revoke.md) — Revoke a shared organization invite link (admin only)
- [`miren cloud invite show`](./cloud-invite-show.md) — Inspect an invitation as its recipient
- [`miren cloud invite update`](./cloud-invite-update.md) — Update an invite's expiry, use cap or groups (admin only)
- [`miren cloud invite url`](./cloud-invite-url.md) — Retrieve a copyable invite URL (admin only)
