# miren run

Manage application task runs

## Usage

```bash
miren run [flags]
```

## Subcommands

- [`miren run attach`](./run-attach.md) — Attach to a running task
- [`miren run cancel`](./run-cancel.md) — End a run early
- [`miren run list`](./run-list.md) — List recent task runs
