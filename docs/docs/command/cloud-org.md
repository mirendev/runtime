# miren cloud org

Cloud organization commands

## Usage

```bash
miren cloud org [flags]
```

## Subcommands

- [`miren cloud org clusters`](./cloud-org-clusters.md) — List clusters and mirrored status in an organization
- [`miren cloud org create`](./cloud-org-create.md) — Create an organization and become its admin
- [`miren cloud org list`](./cloud-org-list.md) — List your Miren Cloud organizations
- [`miren cloud org member`](./cloud-org-member.md) — Cloud organization membership
- [`miren cloud org show`](./cloud-org-show.md) — Show organization details and membership
- [`miren cloud org user-search`](./cloud-org-user-search.md) — Search existing organization members for group membership
