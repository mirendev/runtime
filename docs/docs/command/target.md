# miren target

Manage deployment targets

## Usage

```bash
miren target [flags]
```

## Subcommands

- [`miren target add`](./target-add.md) — Add a deployment target
- [`miren target list`](./target-list.md) — List deployment targets
- [`miren target remove`](./target-remove.md) — Remove a deployment target
