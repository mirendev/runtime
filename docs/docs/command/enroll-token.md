# miren enroll-token

Single-use cluster enrollment credentials

## Usage

```bash
miren enroll-token [flags]
```

## Subcommands

- [`miren enroll-token create`](./enroll-token-create.md) — Mint a cluster enrollment credential and bootstrap config (admin only)
- [`miren enroll-token list`](./enroll-token-list.md) — List enrollment token status without secrets
- [`miren enroll-token revoke`](./enroll-token-revoke.md) — Revoke an unused cluster enrollment token (admin only)
- [`miren enroll-token show`](./enroll-token-show.md) — Show enrollment token state and bootstrap progress
