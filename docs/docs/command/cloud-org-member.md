# miren cloud org member

Cloud organization membership

## Usage

```bash
miren cloud org member [flags]
```

## Subcommands

- [`miren cloud org member add`](./cloud-org-member-add.md) — Add an existing Cloud user to an organization (admin only)
- [`miren cloud org member list`](./cloud-org-member-list.md) — List organization members
- [`miren cloud org member remove`](./cloud-org-member-remove.md) — Remove an organization member (admin only)
- [`miren cloud org member set-role`](./cloud-org-member-set-role.md) — Set an organization member's role (admin only)
