# miren cloud app

Cloud app visibility commands

## Usage

```bash
miren cloud app [flags]
```

## Subcommands

- [`miren cloud app history`](./cloud-app-history.md) — List mirrored app deployment history (latest 50)
- [`miren cloud app list`](./cloud-app-list.md) — List mirrored apps across an organization
- [`miren cloud app logs`](./cloud-app-logs.md) — Fetch bounded live app or build logs through Miren Cloud
- [`miren cloud app routes`](./cloud-app-routes.md) — Show mirrored app routes and sync state
- [`miren cloud app show`](./cloud-app-show.md) — Show mirrored app details, deployments and health
