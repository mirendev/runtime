# miren auth provider

Identity provider management

## Usage

```bash
miren auth provider [flags]
```

## Subcommands

- [`miren auth provider add`](./auth-provider-add.md) — Add an identity provider for route protection
- [`miren auth provider list`](./auth-provider-list.md) — List identity providers
- [`miren auth provider remove`](./auth-provider-remove.md) — Remove an identity provider
- [`miren auth provider show`](./auth-provider-show.md) — Show an identity provider
