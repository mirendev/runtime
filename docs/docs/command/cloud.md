# miren cloud

Miren Cloud HTTP API commands

## Usage

```bash
miren cloud [flags]
```

- [`miren cloud me`](./cloud-me.md) — Show your Cloud profile, organizations and enabled features

- [`miren cloud user`](./cloud-user.md) — Cloud user discovery
- [`miren cloud volume`](./cloud-volume.md) — Cloud volume and backup inventory
