# miren cloud

Miren Cloud authentication

## Usage

```bash
miren cloud [flags]
```

## Subcommands

- [`miren cloud login`](./cloud-login.md) — Authenticate with miren.cloud
- [`miren cloud logout`](./cloud-logout.md) — Remove local authentication credentials
- [`miren cloud whoami`](./cloud-whoami.md) — Display information about the current authenticated user
