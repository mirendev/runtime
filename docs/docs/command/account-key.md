# miren account key

Cloud authentication keys

## Usage

```bash
miren account key [flags]
```

## Subcommands

- [`miren account key list`](./account-key-list.md) — List your Cloud authentication keys, including revoked keys
- [`miren account key revoke`](./account-key-revoke.md) — Revoke a Cloud authentication key without removing local credentials
